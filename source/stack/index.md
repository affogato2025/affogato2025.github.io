## 网站技术栈

- **框架**：Hexo 7  
- **主题**：Butterfly 5  
- **托管**：GitHub Pages  
- **包管理**：npm  
- **评论系统**：Utterances（基于 GitHub Issues）

## 常用命令

```bash
npm run clean
npm run build
cmd /c deploy.bat
```

## 维护策略

- 每次改动先本地构建再发布。  
- 保持菜单和页面一一对应，避免空链接。  
- 通过分类和标签增强内容可发现性。
